# imagens-temp

Imagens dos slides da defesa da dissertação ("Apresentação da defesa — esboço", Google Slides). Repositório
temporário e público: o Google Slides busca cada imagem pelo endereço

    https://raw.githubusercontent.com/jmbrasil/imagens-temp/main/<arquivo>

(o Slides guarda uma cópia ao inserir a imagem; o endereço só precisa funcionar na hora de inserir ou trocar).

- Desde 2026-10-21 as imagens são geradas direto aqui, na cópia local ao lado do repositório da dissertação
  (`../imagens-temp`); antes ficavam em `output/arquivos/imagens_apresentacao/` da dissertação e eram publicadas pelo
  repositório do painel (jmbrasil/painel-estudos-dissertacao).
- Publicar: `python painel/publicar_imagens_apresentacao.py` no repositório da dissertação (fgv_dissertacao_python).
- Apagar este repositório depois da defesa.
